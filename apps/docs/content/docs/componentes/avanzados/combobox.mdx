## Uso y comportamiento

Puede usarse dentro de Field. El buscador auxiliar no envía otro valor al formulario. Enter confirma; Escape conserva el valor anterior. Para un campo obligatorio, proporciona name y required.

Importa `Combobox` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
