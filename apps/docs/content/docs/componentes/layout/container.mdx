## Cuándo usarlo

- Dentro de cada `Section`, para que el contenido no se estire en pantallas grandes.
- Con `size="prose"` (unos 65 caracteres por línea) para artículos y textos legales.

**No lo anides**: un `Container` dentro de otro duplica los márgenes. Para limitar solo un bloque
de texto, usa `style={{ maxWidth }}` o `Prose`.

## Tamaños

| `size` | Ancho máximo | Uso |
| --- | --- | --- |
| `sm` | 40rem | Formularios cortos, mensajes |
| `md` | 48rem | Artículos con imágenes, FAQ |
| `lg` | 64rem | Contenido con dos columnas |
| `xl` | 80rem | **Por defecto**. Secciones de página |
| `2xl` | 96rem | Galerías y rejillas amplias |
| `prose` | ~65ch | Texto largo |
| `full` | 100% | Solo margen lateral |

`flush` quita el margen lateral, para contenido que ya gestiona su propio espacio (un carrusel a
sangre, por ejemplo).

## Accesibilidad

El margen lateral es fluido y nunca baja de 16px, así el texto no toca el borde de la pantalla en
móvil ni obliga a hacer scroll horizontal (WCAG 1.4.10, reflujo).
