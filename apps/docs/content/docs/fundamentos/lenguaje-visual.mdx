Betterlibs UI tiene un estilo propio, **Profundidad suave**: superficies en capas con un filo de
luz, bordes finos translúcidos, degradados discretos del color de marca y movimiento con
intención. Se reconoce a primera vista y, a la vez, se adapta a cualquier marca porque todo se
calcula a partir de tus tokens.

## Los cinco principios

1. **Capas, no cajas.** Las superficies se separan con luz y sombra, no con bordes grises. Cada
   superficie lleva un anillo de 1px translúcido, un filo de luz en el borde superior y una
   sombra suave (`--bl-elevation-0` a `--bl-elevation-4`).
2. **La marca brilla, no grita.** El color de marca aparece en degradados cortos (del acento a su
   tono vecino), halos y tintes al 6–30 %. Los rellenos sólidos se reservan para la acción
   principal.
3. **Los detalles responden.** Todo lo interactivo reacciona: los botones se elevan y proyectan
   un halo de color, las casillas dibujan su marca, los interruptores rebotan, las pestañas
   deslizan su indicador y las tarjetas enlazadas se elevan.
4. **Texto primero.** Inter con rasgos de legibilidad, titulares con tracking negativo y
   entradillas en gris medio. El degradado en texto se usa en una o dos palabras por página.
5. **Accesible siempre.** Los efectos son decorativos: el contraste lo garantizan los colores de
   base. El foco mantiene un anillo sólido (más un halo). Con «reducir movimiento» se eliminan
   las animaciones y en modo de alto contraste se recuperan los bordes del sistema.

| Token | Para qué sirve |
| --- | --- |
| `--bl-elevation-0…4` | Anillo + sombra + filo de luz, de plano a flotante |
| `--bl-gradient-surface` | Fondo de tarjetas y paneles (casi plano, con un matiz hacia abajo) |
| `--bl-gradient-accent` | Relleno de la acción principal (acento → acento hover) |
| `--bl-shadow-accent` | Sombra de color de la acción principal (y `-hover`) |
| `--bl-gradient-border`, `--bl-gradient-border-accent` | Bordes degradados de 1px |
| `--bl-color-glass`, `--bl-color-glass-border` | Superficies translúcidas con desenfoque |
| `--bl-color-accent-tint`, `--bl-color-accent-glow` | Tinte (6–10 %) y halo (30–40 %) de la marca |
| `--bl-ring-halo` | Halo que acompaña al anillo de foco |
| `--bl-gradient-text` | Degradado para texto (del color de texto al de acento) |

Todos se construyen con `color-mix()` a partir de los tokens semánticos: cambian solos con
`createTheme({ brand })` y con el modo oscuro. Si defines un tema en un selector propio, se
recalculan también dentro de él.

## Fondos de sección

`Section` (y todos los bloques) aceptan `background` para añadir un fondo decorativo que se
difumina hacia los bordes:

| `background` | Uso |
| --- | --- |
| `grid` | Rejilla fina, para secciones técnicas o de producto |
| `dots` | Trama de puntos |
| `glow` | Resplandor de la marca desde arriba (por defecto en `Hero`) |
| `mesh` | Varios resplandores de color, para portadas y CTAs |
| `noise` | Grano sutil que da textura a un fondo plano |

## Tipografía

La identidad usa **Inter** (variable). Instálala y cárgala una vez; si no está, se usa la
tipografía del sistema sin romper nada:

```bash
pnpm add @fontsource-variable/inter
```

```tsx
import '@fontsource-variable/inter'
import '@betterlibs/tokens/index.css'
import '@betterlibs/react/styles.css'
```

Para usar otra, pásala a `createTheme({ fontSans, fontDisplay })`.

## Densidad

Añade `data-density="compact"` a cualquier contenedor (o a `<html>`) para reducir la altura de
los controles (botones y campos pasan de 44 a 36px), útil en paneles y tablas. Los objetivos
táctiles siguen por encima del mínimo de WCAG 2.2 (24px).

```tsx
<div data-density="compact">
  <Button size="sm">Filtrar</Button>
</div>
```

## Cómo se aplica en cada componente

| Componente | Detalle de la identidad |
| --- | --- |
| `Button` | Degradado con filo de luz, halo de color, destello al pasar el ratón, pulsación con escala |
| `Card`, `IconTile` | Superficies en capas, bordes degradados, cristal y halos |
| Campos (`Input`, `Select`…) | Superficie con sombra interior; al enfocar, borde de 2px y halo |
| `Checkbox`, `Radio`, `Switch` | La marca se dibuja, el punto crece, el interruptor rebota |
| `Tabs` | Indicador que se desliza entre pestañas |
| `Badge` | Filo translúcido del propio color y punto que late (`pulse`) |
| `SectionHeader` | Antetítulo en cápsula con borde degradado |
| `Heading`, `GradientText` | Titulares con degradado de la marca |
| Overlays | Cristal con desenfoque, elevación 3–4 y fondo desenfocado en diálogos |
| `Header` | Cristal translúcido al fijarse, sombra al hacer scroll |
| Bloques | Hero con resplandor y marco de imagen, cifras con degradado, plan destacado con halo |
