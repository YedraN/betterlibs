```tsx
<Field label="Tamaño de la empresa" name="tamano" required>
  <Select placeholder="Selecciona una opción" options={opciones} />
</Field>
```

## Cuándo usarlo

Para elegir una opción de una lista larga (provincias, sectores). Es un `<select>` nativo: lo más
accesible y, en móvil, abre el selector del sistema.

<Callout title="¿Select o RadioGroup?">
  Con **menos de 5 opciones**, un `RadioGroup` es más rápido: se ven todas sin abrir nada.
</Callout>

## Opciones

- `placeholder`: primera opción vacía. Si el campo es obligatorio, no se puede volver a elegir y la
  validación exige una opción real.
- `options`: opciones como datos (con grupos `{ label, options }`), o `<option>` como hijos.
- `multiple` y `htmlSize` para listas de selección múltiple (poco recomendables: usa casillas).

## Accesibilidad

Teclado y lectores de pantalla nativos. Dentro de un `Field` recibe etiqueta, ayuda y error.
