## Breakpoints

Mobile-first: el estilo base es para móvil y cada breakpoint **añade** cambios hacia arriba.

| Nombre | Desde | Dispositivo típico |
| --- | --- | --- |
| `base` | 0px | Móvil |
| `sm` | 640px | Móvil grande |
| `md` | 768px | Tableta |
| `lg` | 1024px | Portátil |
| `xl` | 1280px | Escritorio |

## Rejilla

Columnas por breakpoint:

<Preview>
  <Grid columns={{ base: 1, sm: 2, lg: 4 }} gap="4">
    <Box padding="6" tone="accent" radius="md"><Text align="center">1</Text></Box>
    <Box padding="6" tone="accent" radius="md"><Text align="center">2</Text></Box>
    <Box padding="6" tone="accent" radius="md"><Text align="center">3</Text></Box>
    <Box padding="6" tone="accent" radius="md"><Text align="center">4</Text></Box>
  </Grid>
</Preview>

```tsx
<Grid columns={{ base: 1, sm: 2, lg: 4 }} gap="4">…</Grid>
```

O deja que la rejilla calcule cuántas columnas caben con un ancho mínimo por elemento (ideal para
logos o tarjetas de equipo):

```tsx
<Grid minItemWidth="14rem">…</Grid>
```
