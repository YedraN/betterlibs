```tsx
<ButtonGroup stackBelow="sm" aria-label="Acciones del hero">
  <Button>Solicitar demo</Button>
  <Button variant="outline">Ver precios</Button>
</ButtonGroup>
```

## Cuándo usarlo

Para acciones relacionadas que van juntas: la principal y su alternativa, o un conjunto de
opciones de la misma barra.

- `attached`: los botones se unen en un solo control (opciones de vista, filtros).
- `stackBelow`: por debajo del breakpoint se apilan a todo el ancho, cómodo en móvil.
- `align`: `start`, `center` o `end`.

## Accesibilidad

Si el grupo necesita contexto, dale un `aria-label` («Vista», «Acciones del artículo»): pasa a ser
un `role="group"` con nombre. El orden del código es el orden de tabulación: la acción principal,
primero.
