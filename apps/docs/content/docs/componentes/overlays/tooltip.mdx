```tsx
<Tooltip content="Descargar en PDF">

</Tooltip>
```

## Cuándo usarlo

Para hacer visible el nombre de un botón de icono o añadir una aclaración breve.

**No aparece en pantallas táctiles**: nunca pongas ahí información imprescindible. Y solo texto: sin
enlaces ni botones dentro (no se puede llegar a ellos).

## Opciones

- `content`: el texto; `side` y `align` para colocarlo.
- `delay`: espera antes de mostrarse al pasar el ratón (300 ms). Al enfocar con el teclado aparece
  al momento.

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Tab` | Al enfocar el elemento aparece el tooltip |
| `Escape` | Lo oculta |

- Se anuncia como descripción del elemento (`aria-describedby`).
- Se puede pasar el ratón por encima sin que desaparezca (WCAG 1.4.13).
- En un `IconButton`, el nombre accesible ya lo da `label`; el tooltip solo lo hace visible.
