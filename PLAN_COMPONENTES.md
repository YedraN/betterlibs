# Ampliación del catálogo

Orden aprobado por el usuario el 14 de octubre de 2026. La aceptación manual de fase 8 sigue
aplazada; no se da por hecha al completar esta ampliación.

Cada entrega debe tener API tipada, UI base/editorial y claro/oscuro, comportamiento a 320 px
y con texto ampliado, teclado/foco y semántica accesible, estados pertinentes y limpieza de
eventos/URLs/operaciones asíncronas. Incluye demo real, documentación y comprobaciones del
comportamiento y errores. Las acciones de servidor permanecen a cargo del consumidor.

Los componentes avanzados se ofrecen desde `@betterlibs/react/advanced` con CSS optativo.
La entrada básica conserva sus presupuestos. No se añade un motor de arrastre a toda la UI.
