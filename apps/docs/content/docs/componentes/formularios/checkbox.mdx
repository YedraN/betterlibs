## Cuándo usarlo

- **Suelta**: confirmar algo («Acepto la política de privacidad», «Quiero recibir el boletín»).
- **En grupo**: elegir varias opciones de una lista. Las marcadas llegan como lista
  (`formData.getAll('servicios')`).

Para una sola opción entre varias, `RadioGroup`. Para activar algo con efecto inmediato, `Switch`.

## Opciones

- `indeterminate`: estado mixto para «Seleccionar todo».
- `variant="card"` (en el grupo o en cada casilla): opciones en tarjetas clicables.
- `CheckboxGroup required`: exige al menos una (lo valida `Form`, que muestra «Selecciona al menos
  una opción»); las casillas no llevan `required` individual.
- `orientation="horizontal"` para pocas opciones cortas.

## Textos

- Casillas en positivo: «Quiero recibir el boletín», no «No quiero no recibir…».
- **RGPD**: las casillas de consentimiento nunca van marcadas por defecto.

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Espacio` | Marca o desmarca |
| `Tab` | Pasa a la siguiente casilla |

Toda la etiqueta es clicable. El grupo es un `<fieldset>` con `<legend>`: la pregunta se anuncia
al entrar.
