## Cuándo usarlo

Para agrupar **acciones** secundarias bajo un botón: compartir, cambiar de idioma, más opciones.
Para la navegación principal de la web, usa [`NavigationMenu`](/docs/componentes/navegacion/navigation-menu);
para elegir un valor en un formulario, `Select` o `RadioGroup`.

## Piezas

- `DropdownMenuItem`: opción con `icon`, `hint` (atajo o dato a la derecha), `tone="danger"` y
  `asChild` para enlaces. `onSelect` se ejecuta con clic, Enter o Espacio.
- `DropdownMenuCheckboxItem` y `DropdownMenuRadioGroup` + `DropdownMenuRadioItem`: opciones marcables.
- `DropdownMenuLabel`, `DropdownMenuSeparator`, `DropdownMenuGroup`.
- `DropdownMenuSub`, `DropdownMenuSubTrigger`, `DropdownMenuSubContent`: submenús.

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Enter` / `Espacio` / `↓` | Abren el menú desde el botón |
| `↑` `↓` / `Inicio` / `Fin` | Recorren las opciones |
| Letra | Salta a la opción que empieza por ella |
| `→` / `←` | Abren / cierran un submenú |
| `Escape` | Cierra y devuelve el foco al botón |
