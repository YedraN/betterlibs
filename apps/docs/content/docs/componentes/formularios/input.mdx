## Tipo y autocompletado

Elige bien `type`, `autoComplete` e `inputMode`: el móvil muestra el teclado correcto y el
navegador rellena los datos con un toque (WCAG 1.3.5).

| Dato | Props recomendadas |
| --- | --- |
| Nombre | `autoComplete="given-name"` / `"family-name"` |
| Email | `type="email" autoComplete="email"` |
| Teléfono | `type="tel" autoComplete="tel"` |
| Empresa | `autoComplete="organization"` |
| Código postal | `autoComplete="postal-code" inputMode="numeric"` |
| Web | `type="url" autoComplete="url"` |
| Contraseña nueva | `type="password" autoComplete="new-password"` |

## Opciones

- `prefix` y `suffix`: texto fijo decorativo («+34», «€»). Incluye la unidad también en la etiqueta.
- `iconStart` e `iconEnd`: iconos decorativos.
- `type="password"`: botón para ver la contraseña (`passwordToggle={false}` lo quita).
- `size`: `sm`, `md` (44px) o `lg`. En pantallas táctiles el texto nunca baja de 16px (así iOS no
  hace zoom).
- `className` y `style` van al marco; `ref` y el resto de props, al `<input>`.

## Accesibilidad

- Dentro de un `Field` recibe etiqueta, ayuda y error automáticamente.
- El botón de contraseña usa `aria-pressed` y el nombre «Mostrar contraseña».
- Anillo de foco siempre visible al escribir (no solo con teclado).
