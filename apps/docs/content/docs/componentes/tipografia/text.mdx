```tsx
<Text variant="lead">Acompañamos a pymes en fiscalidad y estrategia.</Text>
<Text as="span" size="sm" tone="muted">Actualizado hace 2 días</Text>
```

## Variantes

| `variant` | Uso |
| --- | --- |
| `body` | Texto normal (por defecto) |
| `lead` | Entradilla bajo un titular |
| `eyebrow` | Antetítulo corto en mayúsculas («SERVICIOS») |
| `caption` | Pies de foto y notas |
| `label` | Etiquetas de datos y metadatos |

`size`, `tone`, `weight` y `align` ajustan cada variante; `lines` corta el texto a N líneas.

## Accesibilidad

- El texto cortado con `lines` sigue entero en el DOM (los lectores de pantalla lo leen completo),
  pero quien ve la pantalla no: no cortes información imprescindible.
- `tone="subtle"` y `muted` cumplen contraste AA sobre los fondos del sistema; no los uses sobre
  imágenes.
