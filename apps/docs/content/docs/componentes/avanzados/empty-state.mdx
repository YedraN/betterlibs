## Uso y comportamiento

title y description son obligatorios. actions contiene controles reales con nombres concretos. compact sirve para paneles pequeños. No marques el estado vacío normal como una alerta.

Importa `EmptyState` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
