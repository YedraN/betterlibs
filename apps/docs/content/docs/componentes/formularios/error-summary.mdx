## Cuándo usarlo

`Form` ya lo muestra y enfoca solo al enviar con errores. Úsalo suelto cuando el formulario se
valida en el servidor y la página se recarga (sin JavaScript), o con tu propia librería de
formularios.

## Textos

- Título que invita a actuar: «Revisa los siguientes campos» (`title`).
- Un elemento por error, con el nombre del campo y un mensaje que explique cómo corregirlo.

## Accesibilidad

- Cada error es un enlace que lleva el foco al campo (con `id`) y lo centra en pantalla.
- Recibe el foco programáticamente (`tabIndex={-1}`): al llegar, el lector de pantalla lee todo su
  contenido. Si lo muestras tú, llévale el foco.
