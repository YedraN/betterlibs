
## Cuándo usarlo

Cuando el contenido llega ya escrito y no puedes poner un componente en cada elemento: artículos
del blog, páginas legales, fichas de producto desde un CMS, Markdown. Para maquetar una página,
usa los componentes (`Heading`, `Text`, `Stack`…).

## Qué incluye

Titulares (`h2`-`h4`), párrafos, enlaces, listas, citas, tablas (con scroll horizontal si no
caben), código, imágenes con pie, separadores y `<mark>`. El ancho se limita a unos 65 caracteres
por línea y `size="lg"` agranda el texto para lecturas largas.

Todos los estilos usan `:where()`: tienen especificidad cero y cualquier clase tuya los sobrescribe.

## Accesibilidad

- Revisa que el contenido empiece por `h2` si la página ya tiene su `h1`.
- Los enlaces están siempre subrayados y los titulares tienen `scroll-margin` para no quedar
  tapados por una cabecera fija al saltar a un ancla.
