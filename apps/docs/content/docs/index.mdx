Betterlibs combina una UI basada en tokens con movimiento optativo. Puedes empezar con una
página estática, elegir un acabado editorial y añadir entradas o continuidad donde expliquen
una interacción. Los controles conservan teclado, foco y estados; el contenido permanece visible
cuando no hay efectos.

## Decide con ejemplos reales

La UI estática funciona sin Motion. El preset se aplica con data-preset; el proveedor de animación
no añade DOM y no sustituye al router. Sigue [SSR y preferencias](/docs/guias/ssr-y-preferencias),
[composición y foco](/docs/guias/composicion-con-radix) y [costes](/docs/guias/rendimiento).

El código está en desarrollo. La fase 6 verificó 149 pruebas unitarias y 370 recorridos en
Chromium; las referencias entre motores, lectores de pantalla y mediciones del rediseño siguen
pendientes del cierre de fase 8. [Calidad y límites](/docs/recursos/calidad) distingue lo medido de
lo pendiente. [Migración](/docs/guias/migracion-editorial) permite adoptar el estilo por partes.
