## Cuándo usarlo

Delante del título de una tarjeta o característica, para que el icono tenga presencia sin
competir con el texto. Es el mismo estilo que usan `FeatureGrid`, los mega menús y la línea de
tiempo.

## Variantes

- `tone`: `accent` (degradado suave de la marca), `solid` (degradado intenso con brillo) o
  `neutral` (superficie gris elevada).
- `size`: `sm` (36px), `md` (44px) o `lg` (56px). El icono se escala solo.

## Accesibilidad

Es decorativa y lleva `aria-hidden`: el texto que la acompaña debe explicar el contenido.
