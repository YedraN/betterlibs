```tsx
  Jornada «Cierre fiscal 2026»: 12 de noviembre en Madrid.

```

## Cuándo usarlo

Para un anuncio breve de toda la web: un evento, un lanzamiento, un cambio de horario. Un solo
mensaje, corto y con un enlace como mucho. No lo uses para avisos legales ni para el aviso de
cookies ([`CookieConsent`](/docs/bloques/cookies)).

## Opciones

- `tone`: `brand` (por defecto), `neutral`, `dark`, `info` o `warning`.
- `dismissible` + `storageKey`: el cierre se recuerda en `localStorage` entre visitas.

## Accesibilidad

Es una región con nombre («Anuncio»; `label`) que se encuentra al navegar por regiones, sin
interrumpir con anuncios automáticos. El botón de cerrar se llama «Cerrar anuncio».
