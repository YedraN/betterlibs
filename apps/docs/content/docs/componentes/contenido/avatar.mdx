```tsx
<AvatarGroup max={3}>{personas.map((p) => <Avatar key={p.id} name={p.nombre} />)}</AvatarGroup>
```

## Cuándo usarlo

Para identificar a personas (autores, equipo, testimonios) u organizaciones (`shape="square"`).
Si la foto falla o no existe, se muestran las iniciales de `name`.

## Accesibilidad

- El texto alternativo es `name` por defecto. Si el nombre ya aparece al lado (lo habitual), usa
  `alt=""` para que no se lea dos veces.
- `AvatarGroup` resume los que no caben como «+2» y lo anuncia como «y 2 más» (`moreLabel`).
