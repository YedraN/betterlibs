## Cuándo usarlo

Para dar contexto que la vista ya da por otros medios pero un lector de pantalla necesita: el
destino de un «Leer más», la unidad de una cifra, el título de una sección que visualmente se
entiende por la maquetación.

**No lo uses** para esconder texto de relleno para buscadores ni para contenido interactivo que no
se vea (un botón invisible pero enfocable confunde a quien navega con teclado). Para eso existe
`focusable`, que lo hace visible al recibir el foco (como `SkipLink`).
