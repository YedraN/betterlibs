## Cuándo usarlo

Para respuestas de más de una frase: un mensaje, una descripción. El número de filas (`rows`)
sugiere cuánto escribir: ajústalo a la respuesta esperada.

## Opciones

- `showCount` + `maxLength`: contador «120/500» que se vuelve rojo al llegar al límite.
- `autoResize`: crece con el contenido (en navegadores con `field-sizing`).
- `resize`: `vertical` (por defecto) o `none`.

## Accesibilidad

- Con contador, los lectores de pantalla oyen el límite al entrar («Máximo 500 caracteres») y un
  aviso cuando queda poco margen, **solo al dejar de escribir** para no interrumpir
  (`remainingLabel`, `maxLengthLabel`).
- Dentro de un `Field` recibe etiqueta, ayuda y error.
