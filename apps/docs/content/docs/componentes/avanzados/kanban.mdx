## Uso y comportamiento

value contiene tarjetas con id único y columnId válido. Selector y botones Subir/Bajar ofrecen la misma operación sin arrastre. El arrastre HTML evita cargar un motor; no se presupone su soporte en móviles. La aplicación gestiona persistencia y errores de servidor.

Importa `Kanban` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
