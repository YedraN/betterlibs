```tsx
<Alert tone="success" title="Hemos recibido tu mensaje" role="status">
  Te responderemos en 24 horas laborables.
</Alert>
```

## Cuándo usarlo

- Confirmar el resultado de una acción en la misma página («Mensaje enviado»).
- Avisos que afectan a todo el contenido (un cambio de horario, un problema del servicio).
- Errores generales que no son de un campo concreto.

**No lo uses** para errores de formulario (van junto al campo, con [`Field`](/docs/componentes/formularios/field)),
para notificaciones que desaparecen solas ([`toast`](/docs/componentes/feedback/toast)) ni para un
anuncio de toda la web ([`AnnouncementBar`](/docs/componentes/navegacion/announcement-bar)).

## Tonos y opciones

- `tone`: `info`, `success`, `warning`, `danger`, con el icono correspondiente (`icon` lo cambia;
  `false` lo quita).
- `actions`: botones o enlaces bajo el texto.
- `onDismiss`: añade un botón «Cerrar aviso» (`dismissLabel`).

## Textos

Título corto que resume; texto que dice **qué ha pasado y qué hacer**: «No hemos podido enviar tu
mensaje. Revisa tu conexión e inténtalo de nuevo».

## Accesibilidad

- El color siempre va con icono y texto.
- Es estático: si aparece como respuesta a una acción, añade `role="status"` para que se anuncie
  (o `role="alert"` si es un error urgente).
