## Uso y comportamiento

Usa type="single" o "multiple"; value es una lista. Flechas y Home/End recorren botones habilitados sin modificar la selección. Enter o Espacio confirman. No sustituye radios obligatorios de un formulario.

Importa `ToggleGroup` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
