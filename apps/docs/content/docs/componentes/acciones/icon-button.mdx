
## Cuándo usarlo

Para acciones muy reconocibles por su icono (cerrar, buscar, menú) donde no cabe texto. Si el
icono no es evidente, usa un `Button` con texto: la mayoría de iconos no se entienden solos.

## Textos

`label` es obligatorio y describe la **acción**, no el dibujo: «Cerrar menú», no «X»; «Descargar
informe», no «Flecha». También aparece como tooltip nativo al pasar el ratón.

## Accesibilidad

- El `label` es el nombre accesible (`aria-label`).
- Mide 44px en `md`, el objetivo táctil recomendado. En `sm` (36px) cumple el mínimo de WCAG 2.2
  (24px).
- Para mostrar un tooltip propio, envuélvelo en [`Tooltip`](/docs/componentes/overlays/tooltip).
