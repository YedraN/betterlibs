```tsx
<Stack direction="row" gap="3" align="center" stackBelow="md">…</Stack>
```

## Cuándo usarlo

Para colocar elementos seguidos (titular + texto + botones, un icono junto a un texto) con una
separación consistente, sin márgenes sueltos. Para rejillas de tarjetas, usa `Grid`.

## Opciones

- `gap`: un paso de la escala de espaciado (`'4'` = 16px por defecto).
- `direction`: `column` o `row`; `wrap` permite saltar de línea en horizontal.
- `stackBelow`: en horizontal, pasa a vertical por debajo de ese breakpoint.
- `align` y `justify`: alineación en cada eje.

## Accesibilidad

`Stack` solo cambia el aspecto: el orden de lectura es el del código. No uses `order` ni
`flex-direction: row-reverse` para reordenar contenido con significado.
