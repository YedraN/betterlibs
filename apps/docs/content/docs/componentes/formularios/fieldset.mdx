```tsx
<Fieldset legend="Datos de facturación" legendSize="lg">…</Fieldset>
```

## Cuándo usarlo

- Para dividir un formulario largo en partes («Datos de contacto», «Datos de la empresa») con
  `legendSize="lg"`.
- Para agrupar campos que forman una sola respuesta (una dirección, una fecha en tres campos).

Para grupos de casillas o radios, usa `CheckboxGroup` y `RadioGroup`, que ya son un `Fieldset`.

## Accesibilidad

La leyenda se anuncia al entrar en el grupo. `disabled` deshabilita de golpe todos los controles
del grupo (comportamiento nativo). `error` muestra un error común a todo el grupo.
