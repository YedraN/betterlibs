## Uso y comportamiento

value es una lista de uno o dos números. Los extremos no se cruzan. Flechas, Home y End conservan el comportamiento nativo. formatValue comunica unidades. min, max y step deben describir un intervalo válido.

Importa `Slider` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
