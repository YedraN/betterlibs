## Escala fluida

Los tamaños grandes crecen de forma continua entre **360px** y **1280px** de ancho con `clamp()`:
no hay saltos entre breakpoints. Combinan `rem` y `vw`; comprueba el reflow de tu composición
con texto ampliado al 200 %, además de los tamaños de pantalla habituales.

## Buenas prácticas

- **Un solo `h1` por página** y sin saltarse niveles (h2 → h3, nunca h2 → h4). Usa la prop `size`
  de `Heading` si necesitas otro aspecto.
- **Líneas de ~65 caracteres** (`--bl-container-prose`). Las líneas muy largas cansan y hacen perder
  el hilo.
- **Párrafos cortos** y titulares que resuman: la mayoría de visitantes escanea antes de leer.
- **Evita el texto justificado**: crea «ríos» de espacio que dificultan la lectura, sobre todo con
  dislexia.
- **No uses mayúsculas** en textos largos. Solo en antetítulos cortos (`Text variant="eyebrow"`).

## Tu tipografía

El tema habitual usa Inter con fallback del sistema si la fuente no está cargada. Para usar la de tu
marca:

```ts
createTheme({ fontSans: "'Inter', system-ui, sans-serif", fontDisplay: "'Fraunces', serif" })
```

<Callout title="Rendimiento">
  Carga solo los pesos que uses (normalmente 400 y 600) y usa `font-display: swap` para que el texto
  se vea desde el primer momento.
</Callout>


## Tipografía editorial

El preset `editorial` combina Space Grotesk para titulares e Inter para lectura. Las fuentes
se cargan en la aplicación, por ejemplo con Fontsource o `next/font/local`; los tokens incluyen
fallback del sistema.

| Token | Rol |
| --- | --- |
| `--bl-type-hero-size` | Titular de portada, fluido entre 3 y 6.1 rem |
| `--bl-type-heading-size` | Titular de sección, entre 2 y 3.25 rem |
| `--bl-type-lead-size` | Entradilla, entre 1 y 1.125 rem |
| `--bl-type-hero-leading` | Interlineado de portada: 1.02 |
| `--bl-type-heading-leading` | Interlineado de sección: 1.1 |
| `--bl-type-display-tracking` | Espaciado expresivo: −0.055 em |

Usa estas variables en tus composiciones después de activar el preset. El titular de portada
crece entre 360 y 1600 px; los demás tamaños fluidos usan el intervalo común de 360–1280 px.
Evita alturas fijas, permite que los textos largos se partan y comprueba que los controles
siguen siendo utilizables con texto ampliado.
