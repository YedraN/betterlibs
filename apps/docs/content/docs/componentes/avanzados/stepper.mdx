## Uso y comportamiento

steps define id, title y content. Los paneles siguen montados. validate devuelve un mensaje para detener el avance. validate y onComplete reciben AbortSignal; respétala en operaciones remotas. No se completa después de desmontar durante una validación pendiente.

Importa `Stepper` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
