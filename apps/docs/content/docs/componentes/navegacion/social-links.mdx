```tsx
    { network: 'youtube', href: 'https://youtube.com/@norte' },
  ]}
  newTab
/>
```

## Cuándo usarlo

En el pie, en la ficha de una persona del equipo o al final de un artículo. Redes incluidas:
`linkedin`, `x`, `instagram`, `facebook`, `youtube`, `github` y `email`.

## Accesibilidad

- Cada enlace se nombra con la red («LinkedIn») o con `label` (en `TeamGrid`: «Ana Pérez en
  LinkedIn»). El icono es decorativo.
- Con `newTab` se abren en otra pestaña y se anuncia («… (se abre en una pestaña nueva)»).
- Objetivo táctil de 44px (`md`) o 36px (`sm`).
- Los iconos son versiones de trazo; si una red exige su logotipo oficial, pásalo en `icon`.
