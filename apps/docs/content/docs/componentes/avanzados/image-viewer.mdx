## Uso y comportamiento

Cada imagen necesita id, src y alt útil. Las miniaturas reciben de nuevo el foco al cerrar. Flechas navegan entre imágenes. El área ampliada permite desplazamiento con teclado. El fallo de carga conserva los controles.

Importa `ImageViewer` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
