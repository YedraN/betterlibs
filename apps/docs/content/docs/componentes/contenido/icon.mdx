## Cuándo usarlo

Para dar tamaño y color de sistema a un icono de `@betterlibs/icons` (o de otra librería): en
tarjetas de servicios (`contained`), listas de ventajas o mensajes de estado. Dentro de botones no
hace falta: `Button` ya coloca sus iconos.

## Accesibilidad

- Sin `label`, el icono es **decorativo** (`aria-hidden`): lo normal cuando acompaña a un texto.
- Con `label`, se anuncia como imagen con ese nombre: úsalo si el icono aporta información que no
  está en el texto.
