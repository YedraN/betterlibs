## Cuándo usarlo

Para alternar vistas del mismo nivel que no hace falta ver a la vez: servicios, sedes, periodos.

**No escondas en pestañas** contenido que se deba leer entero o comparar: lo que está en una
pestaña oculta pasa desapercibido. Para preguntas frecuentes, `Accordion`.

## Opciones

- `variant`: `line` (subrayado, por defecto) o `pill` (botones sobre un fondo).
- `orientation="vertical"` y `fullWidth` (pestañas a partes iguales).
- `activationMode="manual"`: la pestaña se activa con Enter en vez de al moverse con las flechas
  (útil si cada panel carga datos).
- En móvil, la lista hace scroll horizontal si no cabe.

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Tab` | Entra en la pestaña activa; otro `Tab` pasa al panel |
| `←` `→` (o `↑` `↓` en vertical) | Cambian de pestaña |
| `Inicio` / `Fin` | Primera / última pestaña |

Da un `aria-label` a `TabsList` que describa el conjunto. La pestaña activa se marca con color y
subrayado (o fondo), no solo con color.
