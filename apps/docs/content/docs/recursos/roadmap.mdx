## Cierre de calidad

Quedan Firefox/WebKit, revisión manual con lectores de pantalla, referencias visuales verificadas
y mediciones de rendimiento del rediseño. Una captura de revisión no equivale a una referencia
automatizada y una suite Chromium no acredita todos los navegadores.

## Distribución

Los paquetes se prueban desde el checkout y tarballs locales. La publicación pública, el hosting
y la versión de lanzamiento se decidirán al cierre; 0.0.0 local no demuestra ausencia de consumidores.
Sigue [instalación](/docs/primeros-pasos/instalacion) para una vía de uso reproducible hoy.

## Exploración posterior

Drag completo, comparadores, parallax, marquesinas y escenas de scroll requieren una necesidad y
un presupuesto propios. No se incorporan automáticamente por ampliar el catálogo. La exploración
domMax/layout/drag supera el objetivo de 30 kB y no forma parte de la API aprobada.
