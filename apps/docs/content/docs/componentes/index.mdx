accesibilidad.

## Una API para todos

| Prop | Qué hace |
| --- | --- |
| `variant` | Variante visual (`primary`, `outline`…) |
| `size` | Tamaño (`sm`, `md`, `lg`) |
| `tone` | Significado del color (`accent`, `success`, `danger`…) |
| `asChild` | Aplica el componente sobre su hijo (p. ej. el `Link` de tu router) |
| `as` | Cambia el elemento HTML en componentes de layout y texto |
| `className`, `style`, `ref` | Siempre se pasan al elemento raíz |
