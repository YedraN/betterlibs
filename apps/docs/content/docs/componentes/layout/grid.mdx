```tsx
// Columnas por breakpoint (mobile-first)
<Grid columns={{ base: 1, md: 2, lg: 3 }}>…</Grid>

// O que la rejilla calcule cuántas caben
<Grid minItemWidth="16rem">…</Grid>
```

## Cuándo usarlo

Para elementos del mismo tipo en filas y columnas: tarjetas de servicios, logos, equipo, artículos.
Para una sola fila o columna, usa `Stack`.

## Columnas

- `columns`: un número fijo o un objeto por breakpoint (`base`, `sm`, `md`, `lg`, `xl`). `base`
  aplica siempre y cada breakpoint sobrescribe hacia arriba.
- `minItemWidth`: ancho mínimo de cada celda; la rejilla decide cuántas columnas caben (ignora
  `columns`). Ideal cuando el número de elementos varía.
- `gap` y `rowGap`: separación entre celdas.

## Accesibilidad

Si los elementos forman una lista, dilo: `<Grid as="ul" role="list">` con un `<li>` por celda.
El lector de pantalla anunciará «lista, 6 elementos».
