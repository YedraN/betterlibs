## Uso y comportamiento

snippets contiene id único, label y code literal. El texto se escapa mediante React; no se ejecuta. Los radios son independientes. lineNumbers no se copia. CopyButton se exporta también y comunica permisos denegados sin ocultar el código.

Importa `CodeBlock` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
