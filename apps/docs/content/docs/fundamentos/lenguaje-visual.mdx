La nueva dirección de Betterlibs combina **marfil, carbón y lima**, titulares expresivos y
superficies planas. Busca que las páginas tengan identidad y que cada interacción se entienda.
Está disponible como preset `editorial`. Button, Card, Input, Tabs, Accordion, Dialog, Header y
SectionHeader ya incorporan sus estados editoriales; la adaptación del resto del catálogo continúa.

```tsx
import '@fontsource-variable/inter'
import '@fontsource-variable/space-grotesk'
import '@betterlibs/tokens/index.css'
import '@betterlibs/tokens/editorial.css'
import '@betterlibs/react/styles.css'

<div data-preset="editorial">…</div>
```

## Dirección del preset

- **Lectura:** Space Grotesk en titulares e Inter en el cuerpo; fallback del sistema.
- **Superficies:** contraste entre fondo, tarjeta y bloque invertido; radios contenidos.
- **Acento:** lima en acciones, tinta oscura encima y enlaces legibles en ambos modos.
- **Movimiento:** respuesta breve, entradas discretas y secuencias con espera limitada.
  Los efectos respetan las preferencias de movimiento y no ocultan contenido sin JavaScript.

El piloto completo está en la portada del playground. Storybook incluye
**Fundamentos → Preset editorial**, con controles, contenido largo e informe de contraste.
Los roles compartidos se detallan en [Movimiento](./movimiento) y la configuración en
[Modo oscuro y tema de marca](./modo-oscuro-y-marca).

## Base actual del catálogo

La base actual conserva superficies planas, bordes finos y acabados explícitos. Puedes aplicar
el preset con los mismos componentes. Storybook incluye **Componentes → Editorial → UI prioritaria**:
acciones con carga, validación, contenido variable, diálogos, navegación y texto largo. La barra
**Movimiento** permite cambiar la preferencia CSS sin remontar la story.

## Principios

1. **Jerarquía clara.** Un botón principal por bloque. Las superficies habituales usan un borde
   fino; la elevación se reserva para menús, paneles y tarjetas interactivas.
2. **Texto y espacio.** Inter con fallback del sistema, titulares fluidos y entradillas con ancho
   limitado. Antetítulos de texto por defecto para reducir el peso de las etiquetas.
3. **Estados reconocibles.** Foco visible, errores con texto e icono y cambios discretos de color.
   Los controles del formulario usan superficies limpias sin sombra interior.
4. **Efectos explícitos.** Un efecto destaca un elemento concreto: un CTA, una captura de producto
   o una tarjeta recomendada. Una tarjeta estática no se eleva al pasar el ratón.
5. **Movimiento breve.** Las transiciones acompañan las acciones y respetan movimiento reducido.
   No hay destellos en los botones ni rebote en el interruptor.

## Acabados disponibles

| Componente | Por defecto | Opción decorativa |
| --- | --- | --- |
| `Button` | `appearance="solid"` | `appearance="gradient"` en el principal |
| `Card` | `variant="outline"` | `elevated`, `glass`, `gradient`, `glow` |
| `SectionHeader` | `eyebrowStyle="text"` | `eyebrowStyle="pill"` |
| `Header` | `surface="solid"` | `surface="glass"` |
| `Hero` | `background="none"`, `mediaStyle="plain"` | Fondos decorativos y `mediaStyle="framed"` |
| `CTA` | `panelStyle="plain"` | `panelStyle="glow"` |
| `Heading` | Texto sólido | `tone="gradient"` o `GradientText` |

## Fondos y tokens

`Section` y los bloques aceptan `background="grid"`, `dots`, `glow`, `mesh` o `noise`.
El fondo habitual es `none`. Los tokens de efectos siguen disponibles para estilos propios:
`--bl-elevation-0…4`, `--bl-gradient-accent`, `--bl-color-glass`, `--bl-color-accent-glow` y
`--bl-ring-halo`. Se recalculan con el color de marca y con el modo claro u oscuro.

Para conservar el acabado anterior en un hero:

```tsx
<Hero title="Tu producto, en primer plano" background="glow" mediaStyle="framed" media={captura} />
```

## Tipografía y densidad

La identidad usa Inter variable. Si no está cargada, se usa la tipografía del sistema:

```tsx
import '@fontsource-variable/inter'
import '@betterlibs/tokens/index.css'
import '@betterlibs/react/styles.css'
```

Puedes cambiar las fuentes con `createTheme({ fontSans, fontDisplay })`.
`data-density="compact"` reduce la altura de los controles; el modo habitual conserva 44px en
botones y campos medianos. El foco y los estados de error permanecen visibles en ambos modos.
