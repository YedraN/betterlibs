## Cuándo usarlo

Cuando conoces la forma del contenido que va a llegar (tarjetas, una lista, un artículo): imita su
tamaño para que la página no salte al cargar.

## Accesibilidad

Es **decorativo** (se oculta a lectores de pantalla). Marca el contenedor que carga con
`aria-busy="true"` y, si la espera es larga, anuncia la carga con un `Spinner` o un texto oculto.
La animación se detiene con «reducir movimiento».
