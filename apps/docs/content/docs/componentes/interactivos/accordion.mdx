```tsx
<Accordion headingLevel={3}>
  <AccordionItem value="plazos" title="¿Cuánto tarda un proyecto web?">
    Entre 4 y 8 semanas.
  </AccordionItem>
</Accordion>
```

## Cuándo usarlo

Para contenido que no todos necesitan leer: preguntas frecuentes, condiciones, detalles de un
servicio. Si todo el contenido es importante, muéstralo abierto (o usa el bloque
[`FAQ`](/docs/bloques/conversion) en `variant="columns"`).

## Opciones

- Por defecto, una sola sección abierta que se puede cerrar (`type="single"` + `collapsible`);
  `type="multiple"` permite varias.
- `variant`: `default` (separadores), `bordered` (marco) o `separated` (tarjetas).
- `headingLevel`: nivel del encabezado de cada pregunta (3 por defecto).
- `icon` en cada `AccordionItem`.

## Textos

Preguntas tal como las haría el cliente («¿Hay permanencia?») y respuestas que empiezan por la
respuesta («No. Los planes son mensuales…»).

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Enter` / `Espacio` | Abren o cierran la sección |
| `↑` / `↓` | Pasan de una pregunta a otra |
| `Inicio` / `Fin` | Primera / última pregunta |

Cada pregunta es un encabezado con un botón (`aria-expanded`): aparece en la lista de encabezados
de los lectores de pantalla. Ajusta `headingLevel` a la jerarquía de la página.
