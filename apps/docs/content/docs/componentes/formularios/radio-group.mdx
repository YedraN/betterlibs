## Cuándo usarlo

Para elegir **una** opción entre 2 y 6, todas a la vista. Con más opciones, `Select`. Si la
respuesta es sí/no y activa algo al momento, `Switch`.

## Opciones

- `variant="card"`: cada opción en una tarjeta clicable (planes, tipos de consulta).
- `orientation="horizontal"` para pocas opciones cortas.
- `required`: exige elegir una (validación nativa).

## Textos

La etiqueta del grupo es la **pregunta**; las opciones, respuestas cortas y paralelas. Si hay una
opción recomendada, márcala por defecto con `defaultValue`.

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Tab` | Entra en el grupo (en la opción marcada) y sale de él |
| `↑` `↓` `←` `→` | Cambian de opción |

Es un `<fieldset>` con `role="radiogroup"`, `aria-required` y `aria-invalid`: la pregunta y el
error se anuncian al entrar.
