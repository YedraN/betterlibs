## Cuándo usarlo

Para esperas breves (menos de unos segundos) en las que no sabes cuánto falta. Para contenido que
tarda más y cuya forma conoces (una lista de tarjetas), un [`Skeleton`](/docs/componentes/feedback/skeleton)
da mejor sensación. Dentro de un botón, usa `Button loading`.

## Accesibilidad

- Se anuncia como `role="status"` con el texto de `label` («Cargando…» por defecto).
- Si otro elemento ya anuncia la carga (un botón con `aria-busy`), usa `decorative` para no
  duplicar el anuncio.
- Con «reducir movimiento», gira más despacio.
