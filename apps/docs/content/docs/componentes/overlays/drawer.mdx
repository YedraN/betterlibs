```tsx
<Drawer>

  <DrawerContent title="Filtros" side="right" footer={…}>…</DrawerContent>
</Drawer>
```

## Cuándo usarlo

Mismo comportamiento que `Dialog` (foco atrapado, scroll bloqueado, Escape), pero aparece desde un
lado. Útil para contenido que acompaña a la página: filtros, un carrito, el detalle de un
elemento o el menú móvil (lo usa `Header`).

## Opciones

- `side`: `right` (por defecto), `left`, `bottom` o `top`. Son lados físicos.
- `size`: `sm` (20rem), `md` (28rem), `lg` (36rem) o `full`.
- En móvil, `side="bottom"` es cómodo para acciones rápidas.

## Accesibilidad

| Tecla | Acción |
| --- | --- |
| `Tab` / `Shift+Tab` | Recorren el panel (el foco no sale) |
| `Escape` | Cierra y devuelve el foco |
