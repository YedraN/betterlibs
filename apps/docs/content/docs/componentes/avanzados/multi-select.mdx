## Uso y comportamiento

value es una lista de identificadores. name genera un valor por selección. maxSelected bloquea nuevas opciones, pero permite retirar las elegidas. Las etiquetas tienen botones con nombres completos.

Importa `MultiSelect` desde `@betterlibs/react/advanced` y carga `advanced/styles.css`.
Los temas claro/oscuro y el preset editorial usan los tokens. Las acciones remotas deben comunicar
error y permitir reintento sin perder lo escrito. No dependas solo de iconos o color.
