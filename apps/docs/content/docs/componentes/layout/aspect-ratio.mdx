```tsx
<AspectRatio ratio={16 / 9}>
  <iframe src="https://www.youtube-nocookie.com/embed/ID" title="Presentación de la empresa" />
</AspectRatio>
```

## Cuándo usarlo

Para reservar el hueco de un contenido antes de que cargue (vídeos, mapas, iframes) y evitar que
la página «salte» (CLS). Para imágenes, `Image` ya tiene la prop `ratio`.

## Accesibilidad

Los `iframe` necesitan un `title` que describa su contenido. Si el contenido es de terceros e
instala cookies, envuélvelo en [`ConsentGate`](/docs/bloques/cookies).
