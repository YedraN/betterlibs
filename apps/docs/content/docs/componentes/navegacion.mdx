La navegación es lo que más se repite en una web corporativa: tiene que ser predecible, rápida con
teclado y cómoda en móvil. Todo lo de esta página usa landmarks (`header`, `nav`, `footer`) con
nombre, así que los lectores de pantalla pueden saltar directamente a cada zona.

## Header

Cabecera con enlace para saltar al contenido, logo, navegación principal (enlaces, desplegables y
mega menús), acciones y menú móvil en un panel lateral. Es fija al hacer scroll (`sticky`) y puede
ocultarse al bajar y reaparecer al subir (`hideOnScroll`).

```tsx
import Link from 'next/link'
import { usePathname } from 'next/navigation'

const navigation: NavItem[] = [
  {
    label: 'Servicios',
    groups: [
      {
        label: 'Empresas',
        links: [
          { label: 'Consultoría', href: '/servicios/consultoria', description: 'Plan a 3 años.' },
          { label: 'Auditoría', href: '/servicios/auditoria' },
        ],
      },
    ],
    featured: <CasoDestacado />,
    overview: { label: 'Ver todos los servicios', href: '/servicios' },
  },
  { label: 'Sectores', links: [{ label: 'Industria', href: '/sectores/industria' }] },
  { label: 'Blog', href: '/blog' },
]

<Header
  logo={<Link href="/"><img src="/logo.svg" alt="Norte Consultores, ir a la portada" /></Link>}
  navigation={navigation}
  currentHref={usePathname()}
  linkAs={Link}
  actions={<Button asChild size="sm"><Link href="/contacto">Contacto</Link></Button>}
/>
```

- **Estructura (`NavItem`)**: un enlace (`{ label, href }`), un desplegable (`links`) o un mega menú
  (`groups`, con `featured` para un bloque destacado). `overview` añade «Ver todo» al pie.
- **Página actual**: con `currentHref`, el enlace lleva `aria-current="page"` y su sección se
  marca (color y barra inferior, no solo color).
- **Menú móvil**: por debajo de `collapseBelow` (`lg` por defecto) aparece el botón «Abrir menú»,
  que abre un panel con foco atrapado. Las secciones son desplegables y la de la página actual
  empieza abierta. El panel se cierra al elegir un enlace.
- **Salto al contenido**: la cabecera incluye «Saltar al contenido principal» hacia `#main`. Pon
  `id="main"` en tu `<main>` o cambia el destino con `skipLink`.
- El cambio a menú móvil depende del **ancho de la cabecera** (container queries), no del de la
  ventana: también funciona dentro de un contenedor estrecho.

### Teclado

| Tecla | Acción |
| --- | --- |
| `Tab` | Recorre logo, secciones, enlaces y acciones |
| `Enter` / `Espacio` | Abre o cierra el desplegable de una sección |
| `←` / `→` | Pasan de una sección a otra |
| `Tab` (con el desplegable abierto) | Entra en los enlaces del panel |
| `Escape` | Cierra el desplegable o el menú móvil y devuelve el foco |

`NavigationMenu` y `MobileNav` también se exportan por separado si montas tu propia cabecera.

## AnnouncementBar

Franja sobre la cabecera para un anuncio breve: un evento, un lanzamiento, un cambio de horario.
Con `storageKey`, el cierre se recuerda entre visitas (cambia la clave en cada anuncio nuevo).

<Preview padded={false}>
  <Stack gap="0">
    <AnnouncementBar icon={<CalendarIcon />} action={<a href="#evento">Reserva tu plaza</a>} dismissible>
      Jornada «Cierre fiscal 2026»: 12 de noviembre en Madrid.
    </AnnouncementBar>
    <AnnouncementBar tone="neutral">Del 1 al 31 de agosto atendemos de 8 a 15 h.</AnnouncementBar>
  </Stack>
</Preview>

Un solo mensaje, corto y con un enlace como mucho. No lo uses para avisos legales ni para el aviso de
cookies (ese llegará como bloque propio).

## Footer

Pie con marca, columnas de enlaces, redes sociales, un bloque libre (contacto, boletín) y la franja
legal. Sin estado: funciona en Server Components.

- `tone`: `subtle` (por defecto), `default` o `dark` (fuerza el modo oscuro dentro del pie).

- En España, enlaza siempre **aviso legal**, **privacidad** y **cookies**; y la **declaración de
  accesibilidad** si estás obligado a tenerla.

## SocialLinks

Enlaces a redes con icono, nombre accesible («LinkedIn») y objetivo táctil de 44px. Redes incluidas:
`linkedin`, `x`, `instagram`, `facebook`, `youtube`, `github` y `email`.

## Breadcrumb

Muestra la ruta desde la portada hasta la página actual y permite subir de nivel. La página actual
no es un enlace y lleva `aria-current="page"`.

<Preview>
  <Stack gap="6">
    <Breadcrumb
      items={[
        { label: 'Inicio', href: '#' },
        { label: 'Servicios', href: '#' },
        { label: 'Consultoría fiscal' },
      ]}
    />
    <Breadcrumb
      items={[
        { label: 'Inicio', href: '#' },
        { label: 'Blog', href: '#' },
        { label: 'Fiscalidad', href: '#' },
        { label: 'Novedades del IVA para autónomos en 2026' },
      ]}
    />
  </Stack>
</Preview>

```tsx
<Breadcrumb
  linkAs={Link}
  schemaBaseUrl="https://empresa.com"
  items={[
    { label: 'Inicio', href: '/' },
    { label: 'Servicios', href: '/servicios' },
    { label: 'Consultoría fiscal' },
  ]}
/>
```

- `linkAs` usa el enlace de tu router (`Link` de Next.js, de React Router…).
- Con `schemaBaseUrl` se añaden los datos estructurados `BreadcrumbList` de schema.org: Google puede
  mostrar la ruta en los resultados de búsqueda.
- Colócalas al principio del contenido principal, antes del `h1`. En la portada no hacen falta.

## Pagination

Para listados largos (blog, noticias, casos de éxito). Siempre se ven la primera y la última
página y las vecinas de la actual. En móvil se resume en «Página N de M» con Anterior y Siguiente.

<Preview>
  <Stack gap="8">
    <Pagination page={5} totalPages={12} getHref={(page) => `#pagina-${page}`} />
    <Pagination page={1} totalPages={3} getHref={(page) => `#pagina-${page}`} />
  </Stack>
</Preview>

```tsx
// Enlaces (recomendado): cada página tiene su URL, se puede compartir e indexar.
<Pagination page={pagina} totalPages={total} getHref={(p) => `/blog?pagina=${p}`} linkAs={Link} />

// Botones, si la lista se filtra en el cliente sin cambiar la URL.
<Pagination page={pagina} totalPages={total} onPageChange={setPagina} />
```

- La página actual lleva `aria-current="page"` y un relleno de color (no solo cambio de texto).
- Cada número se anuncia como «Página 3»; los textos se cambian con `pageLabel`,
  `previousLabel`, `nextLabel` y `summaryLabel`.
- Al cambiar de página sin recargar, lleva el foco al principio del listado (por ejemplo, a su
  título con `tabIndex={-1}`) para que quien usa teclado o lector de pantalla no se quede abajo.
