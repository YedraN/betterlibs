## Cuándo usarlo

Para cada bloque horizontal de una página: portada, servicios, testimonios, contacto… Los
[bloques](/docs/bloques) ya lo usan por dentro.

## Fondos y espaciado

| `tone` | Resultado |
| --- | --- |
| `default` | Fondo de la página |
| `subtle` / `muted` | Gris muy suave / suave: alterna con `default` para separar secciones sin líneas |
| `brand` | Tono suave de la marca |
| `dark` / `light` | Fuerzan un modo de color: los componentes de dentro se adaptan solos |

`spacing` (`none`, `sm`, `md`, `lg`) es fluido: menos espacio en móvil, más en escritorio.

## Accesibilidad

Si la sección tiene título, enlázalo con `aria-labelledby`: la sección pasa a ser una **región**
con nombre y los lectores de pantalla pueden saltar a ella. Sin título, es un bloque neutro.
